# Meu Vocabulário v0.4

GitHub Pages向け静的アプリ。既存の4ファイルと `lessons.js` を置き換え、PWA用ファイルを追加してください。

## 今回の更新
- 「前回の授業：ser / estar と日常会話」30問を追加。授業を選択して復習できます。
- 2026-10-20「医薬品・財務」30問を維持。既存の語彙773語とIDを維持。
- PWA化：初回オンライン表示・Service Workerのインストール完了後は、文字データによる学習をオフラインで利用可能。
- 学習履歴は端末のブラウザに保存。クラウド同期は未実装。複数端末での自動統合はできません。
- 音声読み上げは端末側の音声エンジンに依存し、オフライン時に使えない場合があります。

## 文字起こしの注意
提供された文字起こしは英語・カタカナとして誤認識された箇所が多く、ポルトガル語の逐語録ではありません。新セッションは手書きメモを一次資料とし、文字起こしから判別できる話題（不動産・技術者・レストラン等）を補充問題として扱います。先生の正確な発言を復元したものではありません。

## 更新とオフライン
GitHub Pagesにファイルを反映後、オンラインでページを開いてください。更新が表示されない場合はオンライン状態で再読み込みし、必要なら一度タブを閉じて開き直してください。Service Workerの初回登録完了前はオフライン利用できません。

## 履歴
localStorageキーは従来の `por_vocab_v02_*` を維持します。履歴の自動同期はありません。アップデート前のエクスポートを推奨します。
