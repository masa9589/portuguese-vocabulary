# Meu Vocabulário v0.5

GitHub Pagesで動作するブラジルポルトガル語の語彙・授業復習アプリです。

## v0.5の変更点

- 1日あたりの新規語彙の**固定上限を撤廃**。新規学習は1回20語ずつ追加できます。
- 復習待ち（語彙・授業）と期限超過をホームで表示し、語彙復習を優先できるボタンを追加。
- 推奨新規語彙数は復習の負荷に応じて0/5/12語程度に調整しますが、強制的な制限ではありません。
- 授業問題にも日をまたぐ復習予定（1・3・7・14・30日...）を保存。期限到来分と全問やり直しを選べます。
- 以前の授業の回答ログが残っていれば、保守的な翌日復習として引き継ぎます。
- 授業問題の答えを表示した後、ブラウザのポルトガル語読み上げを利用できます。
- **音声タブ**：教材MP3等を端末内のIndexedDBに保存してオフライン再生できます。ファイルはGitHubやクラウドへアップロードされません。
- PWAオフライン用キャッシュをv0.5に更新。初回はオンラインで全ファイルを読み込み、準備後に機内モードでテストしてください。

## 注意

- **GitHub Pagesは静的ホスティングです。** リポジトリURLはファイル管理用で、学習するURLは `https://masa9589.github.io/portuguese-vocabulary/` です。
- 学習履歴はブラウザごとのローカルストレージに保存され、端末間の自動同期はありません。
- 音声読み上げは端末の音声エンジンを使うため、オフラインでは利用できない場合があります。
- 教材の録音ファイルは**このZIPには含まれません**。著作権のある音声を公開リポジトリにアップロードしないでください。
- 旧版の進捗保存キー・既存語彙IDは変更していません。更新前に「学習データのバックアップ・復元」から履歴を書き出すと安全です。
- 語彙データは教材全ページの抽出を保証するものではありません。

## アップロード

ZIPを展開し、`index.html`、`style.css`、`app.js`、`vocabulary.js`、`lessons.js`、`audio.js`、`pwa.js`、`service-worker.js`、`manifest.webmanifest`、各アイコン、`README.md` をリポジトリ直下に上書きアップロードします。
